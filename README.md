## Branches

This repository is organized into branches by simulation study:

- **`main`** — Oracle-weight simulations (Section 5.1): Monte Carlo experiments under known arm gaps across $K \in \{2,4,7,10\}$ platforms and three difficulty settings.
- **[`Simulation-Section-5.2`](../../tree/Simulation-Section-5.2)** — Simulation code for Section 5.2.
- **[`Simulation-Section-5.3`](../../tree/Simulation-Section-5.3)** — Realistic, estimated-weight simulation (Section 5.3): four-platform advertising setting with warm-start weight estimation, compared against oracle performance.

Switch branches above to view the code and notebooks specific to each section.
